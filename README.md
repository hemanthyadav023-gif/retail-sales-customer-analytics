# Retail Sales & Customer Analytics

A data analytics project exploring retail sales performance using Python, SQL, Pandas, and data visualization.

## Project Overview
This project analyzes 2,500 retail transactions to identify sales trends, product performance, customer segments, and business opportunities.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- MySQL
- SQL

## Key Analysis
- Overall revenue, profit, and order KPIs
- Monthly sales and profit trends
- Product and category performance
- City-wise sales analysis
- Customer segment analysis
- Payment method and discount analysis

## Project Structure
- `data/` — Retail sales dataset
- `python/` — Python analysis scripts
- `sql/` — SQL queries
- `visuals/` — Generated charts
- `reports/` — Analysis tables and summary
- `requirements.txt` — Python dependencies

## How to Run
1. Install Python.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Run the analysis: `python python/retail_analysis.py`

## Dataset
The project uses a dataset containing 2,500 retail transaction records.
